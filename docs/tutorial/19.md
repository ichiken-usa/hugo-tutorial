# Hugo チュートリアル: 条件分岐の基本と活用方法

Hugoでは、条件分岐（if-else文）を使用してテンプレート内で動的なロジックを実現できます。このガイドでは、条件分岐の基本から、実用的な使用例やナビゲーションメニューの動的スタイリング方法までを解説します。

- Hugoテンプレートでの条件分岐の構文と使用方法
- 比較演算子と論理演算子（`and`、`or`、`not`）の説明
- 変数を使用した条件分岐の実用例
- `range`関数と条件分岐を組み合わせたナビゲーションメニューの動的スタイリング

## 条件分岐とは？

条件分岐は、テンプレート内で特定の条件に基づいてコードの実行を制御するための構文です。これにより、動的なコンテンツやスタイリングを実現できます。

### 主な特徴

- **ロジックの制御**: 条件が真の場合にのみコードを実行します。
- **Hugo固有の構文**: 演算子がオペランドの前に来る構文を使用します（例: `if eq var1 var2`）。
- **終了タグが必要**: 条件分岐ブロックは必ず`end`タグで閉じる必要があります。

---

## 条件分岐の活用方法

### 1. 基本的な条件分岐の構文

以下は、Hugoでの基本的な条件分岐の例です。

```html
{{ if eq .Title "ホーム" }}
  <p>これはホームページです。</p>
{{ else }}
  <p>これはホームページではありません。</p>
{{ end }}
```

- **`if eq`**: `.Title`が`"ホーム"`と等しい場合に実行。
- **`else`**: 条件が偽の場合に実行。

---

### 2. 比較演算子と論理演算子

Hugoでは、以下の比較演算子と論理演算子を使用できます。

#### 比較演算子

- **`eq`**: 等しい
- **`ne`**: 等しくない
- **`lt`**: より小さい
- **`gt`**: より大きい
- **`le`**: 以下
- **`ge`**: 以上

#### 論理演算子

- **`and`**: 両方の条件が真の場合に実行。
- **`or`**: 少なくとも1つの条件が真の場合に実行。
- **`not`**: 条件を否定。

#### 使用例

```html
{{ if and (eq .Section "blog") (gt .WordCount 500) }}
  <p>このブログ記事は500語以上です。</p>
{{ end }}
```

---

### 3. 変数を使用した条件分岐

条件分岐内で変数を使用して、動的なロジックを実現できます。

```html
{{ $isHome := eq .Title "ホーム" }}
{{ if $isHome }}
  <p>ホームページにようこそ！</p>
{{ end }}
```

---

### 4. `range`関数と条件分岐を組み合わせたナビゲーションメニュー

現在のページをハイライトするナビゲーションメニューを作成する例です。

```html
<ul>
  {{ range .Site.Pages }}
    <li class="{{ if eq .Title $.Title }}active{{ end }}">
      <a href="{{ .URL }}">{{ .Title }}</a>
    </li>
  {{ end }}
</ul>
```

- **`eq .Title $.Title`**: 現在のページタイトルと一致する場合に`active`クラスを追加。

## 重要なポイント

- **条件分岐の役割**: テンプレート内でロジックを制御し、動的なコンテンツを生成します。
- **構文の特徴**: Hugoでは、演算子がオペランドの前に来る構文を使用します。
- **論理演算子の活用**: `and`、`or`、`not`を組み合わせて複雑な条件を作成可能。
- **変数のスコープ**: ループ内では変数のスコープが変わるため、比較には変数を事前に格納することが推奨されます。

---

## 重要な定義・概念

- **条件分岐（if-else文）**: 条件が真か偽かに基づいてコードを実行する構文。
- **演算子**: 値を比較するための記号やキーワード（例: `eq`、`lt`、`gt`）。
- **論理演算子**: 条件を組み合わせるためのキーワード（例: `and`、`or`、`not`）。
- **スコープ**: 変数や値がアクセス可能な範囲。ループ内ではスコープが変化します。

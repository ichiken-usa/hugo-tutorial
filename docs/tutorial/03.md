- ターミナルを使用した Homebrew と Hugo のインストールコマンド
- Hugo インストールの確認方法

## 重要なポイントや説明

- **Homebrew** は Mac 用のパッケージマネージャーで、ソフトウェアのインストールや管理を簡単に行える。
- インストール手順は、Homebrew の公式ウェブサイトからコマンドをコピーし、ターミナルに貼り付けて実行する。
- Homebrew をインストールした後、以下のコマンドで Hugo をインストール:

```bash
  brew install hugo
```

- Hugo のインストール確認方法:
  - which hugo コマンドで Hugo の場所を確認。
  - hugo version コマンドでバージョンを確認。
- インストールが成功すると、エラーメッセージが表示されず、Hugo のバージョン番号が表示される。

## 重要な定義・概念

パッケージマネージャー: 他のプログラムをインストールおよび管理するためのツール。
Homebrew: Mac OS 用の人気のあるパッケージマネージャー。

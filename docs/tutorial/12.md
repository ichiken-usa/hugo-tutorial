## リストテンプレートとは？

リストテンプレートは、Hugoで複数のコンテンツを一覧表示するリストページをレンダリングするために使用されるテンプレートです。ホームページやカテゴリーページなどで利用されます。

### 主な特徴

- **リストページ用**: リストテンプレートは、複数のコンテンツを一覧表示するページ（例: カテゴリーページ）に使用されます。
- **デフォルトの場所**: リストテンプレートは通常、`layouts/_default/list.html`に配置されています。
- **カスタマイズ可能**: テーマのリストテンプレートを上書きして、独自のデザインを適用できます。

---

## リストテンプレートの活用方法

### 1. リストテンプレートの場所

Hugoテーマでは、リストテンプレートは通常以下の場所にあります。

```plaintext
layouts/_default/list.html
```

このファイルを編集することで、リストページのデザインを変更できます。

---

### 2. テンプレートの上書き

テーマのリストテンプレートを上書きするには、プロジェクトの`layouts/_default`フォルダに新しい`list.html`ファイルを作成します。このファイルが優先され、テーマのテンプレートが上書きされます。

---

### 3. Hugo変数の活用

Hugoでは、テンプレート内で以下の変数を使用してコンテンツやメタデータを表示できます。

- **`.Content`**: Markdownファイルのコンテンツを出力します。
- **`.Title`**: フロントマターで定義されたタイトルを表示します。
- **`.URL`**: ページのURLを取得します。

---

### 4. `range`関数を使用したループ処理

`range`関数を使用すると、セクション内のすべてのページをループ処理して一覧表示できます。以下はその例です。

```html
<ul>
  {{ range .Pages }}
    <li><a href="{{ .URL }}">{{ .Title }}</a></li>
  {{ end }}
</ul>
```

このコードは、セクション内のすべてのページタイトルとURLをリストとして表示します。

---

### 5. ナビゲーションメニューの作成

リストテンプレートを使用して、ページタイトルとURLを基にナビゲーションメニューを作成できます。

```html
<nav>
  <ul>
    {{ range .Pages }}
      <li><a href="{{ .URL }}">{{ .Title }}</a></li>
    {{ end }}
  </ul>
</nav>
```

---

## 重要なポイント

- **リストテンプレートの役割**: 複数のコンテンツを一覧表示するページをレンダリングするために使用されます。
- **テンプレートの上書き**: プロジェクト内で独自のテンプレートを作成することで、テーマをカスタマイズ可能。
- **Hugo変数の活用**: `.Content`や`.Title`などの変数を使用して、Markdownファイルのデータをテンプレートに表示できます。
- **`range`関数の利用**: ページをループ処理して、リストやナビゲーションメニューを作成できます。

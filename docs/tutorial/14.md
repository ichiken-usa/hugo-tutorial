# Hugo チュートリアル: ホームページテンプレートの作成と活用方法

Hugoでは、ホームページに特化したテンプレートを作成することで、サイトのトップページをカスタマイズできます。このガイドでは、ホームページテンプレートの基本から作成方法までを解説します。

## ホームページテンプレートとは？

Hugoでは、ホームページは技術的にはリストページとして扱われますが、独自のテンプレートを割り当てることができます。これにより、他のリストページとは異なるデザインや構造を持つトップページを作成できます。

### 主な特徴

- **リストページとしてのホームページ**: ホームページはデフォルトでリストテンプレートを使用します。
- **カスタムテンプレートの作成**: `layouts`フォルダに`index.html`を追加することで、ホームページ専用のテンプレートを作成可能。
- **他のリストページへの影響なし**: カスタムホームページテンプレートは、他のリストページには影響を与えません。

---

## ホームページテンプレートの活用方法

### 1. コンテンツタイプとテンプレートの理解

Hugoには2つの基本的なコンテンツタイプがあります。

- **シングルページコンテンツ**: 個別のコンテンツ（例: ブログ記事）を表示するためのもの。
- **リストページコンテンツ**: 複数のコンテンツを一覧表示するためのもの（例: カテゴリーページやホームページ）。

これらのコンテンツタイプには、それぞれ対応するテンプレートがあります。

- **シングルページテンプレート**: `single.html`
- **リストテンプレート**: `list.html`
- **ホームページテンプレート**: `index.html`（カスタムテンプレートとして作成可能）

---

### 2. カスタムホームページテンプレートの作成

ホームページ専用のテンプレートを作成するには、以下の手順を実行します。

1. プロジェクトの`layouts`フォルダに`index.html`ファイルを作成します。
2. 以下のようなHTML構造を記述します。

    ```html
    <!DOCTYPE html>
    <html>
    <head>
    <title>{{ .Site.Title }}</title>
    </head>
    <body>
    <h1>ようこそ、{{ .Site.Title }}へ！</h1>
    <ul>
        {{ range .Pages }}
        <li><a href="{{ .URL }}">{{ .Title }}</a></li>
        {{ end }}
    </ul>
    </body>
    </html>
    ```

3. Hugoサーバーを再起動して、ホームページの変更をプレビューします。

---

### 3. カスタムテンプレートの優先順位

Hugoでは、`layouts/index.html`が存在する場合、ホームページはこのテンプレートを使用します。他のリストページ（例: カテゴリーページ）は引き続き`list.html`テンプレートを使用します。

---

## 重要なポイント

- **ホームページの特別な扱い**: ホームページはリストページとして扱われますが、独自のテンプレートを持つことができます。
- **カスタムテンプレートの作成**: `layouts/index.html`を作成することで、ホームページ専用のデザインを適用可能。
- **他のリストページへの影響なし**: カスタムホームページテンプレートは、他のリストページには影響を与えません。

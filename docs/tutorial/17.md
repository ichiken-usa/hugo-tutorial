## Hugoの変数とは？

Hugoの変数は、ページやサイトに関する情報をテンプレート内で使用するためのデータです。これにより、動的なコンテンツやスタイリングを簡単に実現できます。

### 主な特徴

- **テンプレート専用**: 変数は`layouts`フォルダ内のテンプレートでのみ使用可能です。
- **一般的な変数**: `.title`、`.date`、`.URL`などの変数は直接アクセス可能です。
- **カスタム変数**: フロントマターで定義されたカスタム変数は`.params`を使用してアクセスします。

---

## Hugo変数の活用方法

### 1. 一般的なページ変数の使用

以下は、一般的なページ変数を使用した例です。

```html
<h1>{{ .Title }}</h1>
<p>公開日: {{ .Date }}</p>
<a href="{{ .URL }}">この記事のリンク</a>
```

- **`.Title`**: ページのタイトルを表示。
- **`.Date`**: ページの公開日を表示。
- **`.URL`**: ページのURLを取得。

---

### 2. カスタムフロントマター変数の使用

Markdownファイルのフロントマターでカスタム変数を定義し、テンプレートで使用できます。

#### Markdownファイルの例

```yaml
---
title: "カスタム変数の例"
date: 2025-05-02
params:
  author: "山田太郎"
  tags: ["Hugo", "チュートリアル"]
---
```

#### テンプレートでの使用例

```html
<p>著者: {{ .Params.author }}</p>
<p>タグ: {{ range .Params.tags }}<span>{{ . }}</span>{{ end }}</p>
```

---

### 3. テンプレート内でのカスタム変数の作成

テンプレート内でカスタム変数を作成するには、ドル記号（`$`）を使用します。

```html
{{ $greeting := "こんにちは" }}
<p>{{ $greeting }}、{{ .Title }}!</p>
```

---

### 4. HTMLとCSSでの変数の活用

変数をHTMLやCSSと組み合わせて、動的なスタイリングを実現できます。

```html
<div style="color: {{ .Params.color }};">
  {{ .Title }}
</div>
```

#### フロントマターでの設定例

```yaml
params:
  color: "blue"
```

---

### 5. Hugo変数の種類

Hugoには、以下のようなさまざまな変数があります。

- **サイト全体の変数**: `.Site.Title`、`.Site.Params`など。
- **ページ変数**: `.Title`、`.Content`、`.Date`など。
- **タクソノミー変数**: `.Terms`、`.Taxonomy`など。
- **ファイル変数**: `.File.Path`、`.File.BaseFileName`など。
- **メニュー変数**: `.Site.Menus`など。
- **Hugo固有の変数**: `.Now`、`.Hugo`など。

## 重要なポイント

- **変数の役割**: ページやサイトに関する情報をテンプレート内で動的に表示するために使用されます。
- **カスタム変数の活用**: フロントマターで定義されたカスタム変数は、`.Params`を使用してアクセス可能。
- **テンプレート専用**: 変数は`layouts`フォルダ内でのみ使用可能。
- **公式ドキュメントの活用**: Hugo公式ドキュメントには、利用可能な変数の詳細が記載されています。

---

## 重要な定義・概念

- **Hugoの変数**: ページやサイトに関する情報をテンプレート内で使用するためのデータ。
- **フロントマター**: Markdownファイルの先頭に記述されるメタデータで、カスタム変数を定義可能。
- **`.Params`**: フロントマターで定義されたカスタム変数にアクセスするための名前空間。
- **カスタム変数**: テンプレート内でドル記号を使用して定義される変数。

# Hugo のフロントマターの概要と活用方法

Hugoでは、フロントマターを使ってコンテンツファイルにメタデータを追加し、サイト全体の整理やテンプレートの強化を行えます。このガイドでは、フロントマターの基本から活用方法までを解説します。

## このガイドで学べること

- Hugoにおけるフロントマターの基本
- フロントマターをコンテンツファイルのメタデータとして活用する方法
- フロントマターを記述するための言語（YAML、JSON、TOML）の違い
- Hugoテンプレートやテーマでのフロントマターの活用方法
- カスタムフロントマター変数の作成とその用途

## フロントマターとは？

フロントマターは、コンテンツファイルの先頭に記述されるメタデータのセクションです。キーと値のペアで情報を定義し、Hugoがサイトの構築時にこれを利用します。

### 主な特徴

- **メタデータの管理**: タイトル、日付、タグ、下書きステータスなどを定義。
- **形式の柔軟性**: YAML、TOML、JSONの3つの形式で記述可能。
- **動的な更新**: フロントマターの値を変更するだけで、サイトのコンテンツが動的に更新される。

---

## フロントマターの形式

Hugoでは、以下の3つの形式でフロントマターを記述できます。

### 1. YAML（デフォルト）

三本のハイフン（`---`）で囲む形式です。

```yaml
---
title: "ブログ記事のタイトル"
date: 2025-05-02T10:00:00+09:00
draft: true
author: "山田太郎"
tags:
  - Hugo
  - フロントマター
---
```

### 2. TOML

三本のプラス記号（`+++`）で囲む形式で、等号（`=`）を使用します。

```toml
+++
title = "ブログ記事のタイトル"
date = "2025-05-02T10:00:00+09:00"
draft = true
author = "山田太郎"
tags = ["Hugo", "フロントマター"]
+++
```

### 3. JSON

波括弧（`{}`）で囲む形式です。

```json
{
  "title": "ブログ記事のタイトル",
  "date": "2025-05-02T10:00:00+09:00",
  "draft": true,
  "author": "山田太郎",
  "tags": ["Hugo", "フロントマター"]
}
```

## フロントマターの活用方法

### 1. テンプレートやテーマでの利用

フロントマターのデータは、Hugoのテンプレートやテーマで利用され、ウェブサイト上に情報を表示するために使用されます。

### 2. カスタムフロントマター変数

独自の変数（例: `author`, `language`）を追加して、コンテンツ情報を拡張できます。これにより、特定のテンプレートやテーマでカスタマイズが可能になります。

### 3. 下書きコンテンツの管理

`draft: true`を設定することで、コンテンツを下書きとしてマークできます。下書きはデフォルトでは公開されませんが、以下のコマンドでプレビューできます。

```bash
hugo server -D
```

## 重要なポイント

- **フロントマターの柔軟性**: YAML、TOML、JSONのいずれかを選択可能。
- **カスタマイズ性**: 独自の変数を追加して、サイトの構造やデザインを柔軟に変更可能。
- **効率的な管理**: フロントマターを活用することで、コンテンツの整理やテンプレートの強化が簡単に行えます。

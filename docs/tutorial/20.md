# Hugo チュートリアル: データフォルダの活用方法

Hugoでは、データフォルダを使用して、JSON、YAML、TOML形式のデータをテンプレート内で活用できます。このガイドでは、データフォルダの基本から、テンプレートでのデータアクセスやループ処理の方法までを解説します。

---

## このガイドで学べること

- Hugoにおけるデータフォルダの基本
- データフォルダに保存できるファイル形式（JSON、YAML、TOML）の種類
- データフォルダをウェブサイトのミニデータベースとして使用する方法
- Hugoテンプレートでデータファイルにアクセスし、ループ処理を行う方法

---

## データフォルダとは？

データフォルダは、Hugoプロジェクト内で外部データファイルを保存するためのディレクトリです。これにより、テンプレート内で構造化されたデータを簡単に利用できます。

### 主な特徴

- **対応形式**: JSON、YAML、TOML形式のファイルをサポート。
- **フロントマターに似た構造**: データファイルは、コンテンツファイルのフロントマターと同様にキーと値のペアで構成されます。
- **テンプレートでのアクセス**: `.Site.Data.filename`を使用してデータにアクセス可能。

---

## データフォルダの活用方法

### 1. データファイルの作成

データフォルダ（`data`ディレクトリ）内にデータファイルを作成します。以下は、`data/states.yaml`の例です。

```yaml
california:
  capital: "Sacramento"
  population: 39538223
texas:
  capital: "Austin"
  population: 29145505
```

---

### 2. テンプレートでのデータアクセス

データファイルの内容にアクセスするには、`.Site.Data`を使用します。

```html
<p>カリフォルニア州の州都: {{ .Site.Data.states.california.capital }}</p>
<p>テキサス州の人口: {{ .Site.Data.states.texas.population }}</p>
```

---

### 3. `range`関数を使用したデータのループ処理

データファイル内のすべての項目をループ処理して表示する例です。

```html
<ul>
  {{ range $state, $info := .Site.Data.states }}
    <li>{{ $state }}: 州都は{{ $info.capital }}、人口は{{ $info.population }}人です。</li>
  {{ end }}
</ul>
```

- **`$state`**: 各州のキー（例: `california`）。
- **`$info`**: 各州のデータ（例: `capital`や`population`）。

---

### 4. データファイル形式の違い

HugoはJSON、YAML、TOML形式をサポートしており、どの形式でも同じ方法でデータにアクセスできます。

#### JSON形式の例（`data/states.json`）

```json
{
  "california": {
    "capital": "Sacramento",
    "population": 39538223
  },
  "texas": {
    "capital": "Austin",
    "population": 29145505
  }
}
```

#### TOML形式の例（`data/states.toml`）

```toml
[california]
capital = "Sacramento"
population = 39538223

[texas]
capital = "Austin"
population = 29145505
```

---

## 重要なポイント

- **データフォルダの役割**: 外部データを保存し、テンプレート内で利用可能にします。
- **`.Site.Data`の活用**: データファイルにアクセスするための方法。
- **`range`関数の使用**: データファイル内の項目をループ処理して表示可能。
- **形式の柔軟性**: JSON、YAML、TOMLのいずれの形式でも同じ方法でデータを操作可能。

---

## 重要な定義・概念

- **データフォルダ**: Hugoプロジェクト内で外部データファイルを保存するためのディレクトリ。
- **`.Site.Data`**: Hugoテンプレート内でデータファイルにアクセスするための名前空間。
- **`range`関数**: コレクション（例: データファイル内の項目）をループ処理するための関数。

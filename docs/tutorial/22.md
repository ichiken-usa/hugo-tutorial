# Hugo チュートリアル: ショートコードテンプレートの活用方法

Hugoでは、ショートコードを使用して、Markdownファイル内で繰り返し使用するHTMLやコンテンツを簡単に挿入できます。このガイドでは、ショートコードの基本から作成方法、変数の渡し方、Markdownのレンダリング方法までを解説します。

- ダブルタグショートコード内のコンテンツへのアクセス方法
- CSSを使用したショートコードコンテンツのスタイリング
- Markdownをショートコード内でレンダリングする方法

---

## ショートコードとは？

ショートコードは、Markdownファイル内で再利用可能なコードスニペットです。これにより、HTMLを繰り返し記述する手間を省き、コンテンツの管理を効率化できます。

### 主な特徴

- **再利用可能**: 繰り返し使用するHTMLやコンテンツを簡単に挿入可能。
- **`layouts/shortcodes`フォルダ**: ショートコードはこのフォルダ内に保存されます。
- **簡単な呼び出し**: ファイル名を拡張子なしで指定してショートコードを呼び出します。

---

## ショートコードの活用方法

### 1. ショートコードの作成

以下は、`layouts/shortcodes/alert.html`に保存するカスタムショートコードの例です。

```html
<div style="color: {{ .Get "color" }}; border: 1px solid;">
  {{ .Inner }}
</div>
```

---

### 2. Markdownファイル内でのショートコードの使用

#### シングルタグショートコード

```markdown
{{< alert color="blue" >}}これは青いアラートです。{{< /alert >}}
```

- **`color="blue"`**: 名前付きパラメータを使用して色を指定。
- **`{{< /alert >}}`**: ダブルタグショートコードの閉じタグ。

---

### 3. パラメータの渡し方

#### 名前付きパラメータ

```markdown
{{< alert color="red" >}}これは赤いアラートです。{{< /alert >}}
```

#### 位置指定パラメータ

```markdown
{{< alert "green" >}}これは緑のアラートです。{{< /alert >}}
```

#### ショートコード内でのパラメータの取得

```html
<div style="color: {{ .Get 0 }};">
  {{ .Inner }}
</div>
```

- **`.Get "color"`**: 名前付きパラメータを取得。
- **`.Get 0`**: 位置指定パラメータを取得。

---

### 4. ダブルタグショートコードと`.Inner`変数

ダブルタグショートコードを使用すると、複数の段落やコンテンツをショートコード内に含めることができます。

```markdown
{{< alert color="yellow" >}}
このアラートには複数の段落があります。

- リスト項目1
- リスト項目2
{{< /alert >}}
```

#### `.Inner`変数

ショートコード内で`.Inner`を使用すると、タグ内のコンテンツにアクセスできます。

---

### 5. Markdownをショートコード内でレンダリング

ショートコード内でMarkdownをレンダリングするには、`%`記号を使用します。

```markdown
{{% alert color="purple" %}}
**このテキストは太字です。**
{{% /alert %}}
```

---

## 重要なポイント

- **ショートコードの役割**: Markdownファイル内で再利用可能なHTMLやコンテンツを簡単に挿入します。
- **パラメータの活用**: 名前付きパラメータや位置指定パラメータを使用して柔軟にデータを渡せます。
- **`.Inner`変数**: ダブルタグショートコード内のコンテンツにアクセス可能。
- **Markdownのレンダリング**: `%`記号を使用してショートコード内でMarkdownをレンダリング可能。

---

## 重要な定義・概念

- **ショートコード**: Markdownファイル内で再利用可能なコードスニペット。
- **シングルタグショートコード**: 単一のタグで使用されるショートコード。
- **ダブルタグショートコード**: 開始タグと終了タグで囲むショートコード。
- **名前付きパラメータ**: キーと値のペアで渡されるパラメータ（例: `color=blue`）。
- **位置指定パラメータ**: 名前を指定せずに位置で渡されるパラメータ（例: `blue`）。
- **`.Get`関数**: ショートコード内で渡されたパラメータを取得するための関数。
- **`.Inner`変数**: ダブルタグショートコード内のコンテンツを格納する変数。
- **Markdownのレンダリング**: `%`記号を使用してショートコード内でMarkdownを有効にする方法。

## 重要なポイントや説明

- 新しい Hugo サイトを作成するには、以下のコマンドを使用:

  ```bash
  hugo new site [サイト名]
  ```

Hugo はサイト用のデフォルトフォルダとファイルを自動的に作成。
各フォルダは、コンテンツ、レイアウト、データ、静的ファイル、テーマ、設定を管理するための特定の役割を持つ。
config.toml ファイルは、Hugo サイトのメイン設定ページとして機能。
ユーザーは、主に content フォルダと themes フォルダを使用してシンプルなサイトを開始可能。より複雑なサイトを構築する場合は、layouts や static リソースを活用。

## 重要な定義・概念

Archetypes: コンテンツの共通メタデータ（例: 著者や言語）を定義するテンプレート。
Content フォルダ: ブログ投稿やページなど、ウェブサイトのすべてのコンテンツを保存。
Data フォルダ: サイトで使用される静的データファイル（例: JSON）を格納するデータベースのような役割。
Layouts フォルダ: ヘッダーやフッターなど、一貫性のあるページ要素のテンプレートを保存。
Static フォルダ: 画像、CSS、JavaScript ファイルなどの静的アセットを保存。
Themes フォルダ: サイトのスタイルに使用できる事前構築されたテーマを格納。
config.toml: サイト全体の設定（例: タイトル、言語、ベース URL）を管理する設定ファイル。

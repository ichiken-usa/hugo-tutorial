# Hugo サイト作成手順とフォルダ構成の概要

Hugoを使って新しいサイトを作成するのはとても簡単です！このガイドでは、新しいサイトの作成方法と、Hugoが自動生成するフォルダ構成についてわかりやすく解説します。

---

## このガイドで学べること

- 新しいHugoサイトの作成方法
- Hugoが自動生成するデフォルトフォルダ構成の概要
- 各フォルダの役割と目的
- `config.toml`ファイルの役割と基本設定

---

## 手順

### 1. 新しいサイトを作成する

新しいHugoサイトを作成するには、以下のコマンドをターミナルで実行します。

```bash
hugo new site [サイト名]
```

これで、Hugoがサイト用のデフォルトフォルダとファイルを自動的に作成します。

---

## フォルダ構成の概要

Hugoが生成するフォルダには、それぞれ特定の役割があります。以下は主なフォルダの説明です。

- **`archetypes`**: コンテンツの共通メタデータ（例: 著者や日付）を定義するテンプレートを保存します。
- **`content`**: ブログ投稿やページなど、ウェブサイトのすべてのコンテンツを保存します。
- **`data`**: サイトで使用される静的データファイル（例: JSONやYAML）を格納します。
- **`layouts`**: ヘッダーやフッターなど、一貫性のあるページ要素のテンプレートを保存します。
- **`static`**: 画像、CSS、JavaScriptファイルなどの静的アセットを保存します。
- **`themes`**: サイトのスタイルに使用できる事前構築されたテーマを格納します。

---

## `config.toml`ファイルの役割

`config.toml`は、Hugoサイト全体の設定を管理する重要なファイルです。このファイルでは、以下のような設定を行います。

- サイトのタイトル
- 使用する言語
- ベースURL
- テーマの指定

たとえば、基本的な設定は以下のようになります。

```toml
baseURL = "https://example.com/"
languageCode = "ja"
title = "私のHugoサイト"
theme = "my-theme"
```

---

## 重要なポイント

- **簡単なスタート**: `content`フォルダと`themes`フォルダを使えば、シンプルなサイトをすぐに開始できます。
- **柔軟なカスタマイズ**: より複雑なサイトを構築する場合は、`layouts`や`static`フォルダを活用しましょう。
- **設定の中心**: `config.toml`ファイルを編集することで、サイト全体の設定を簡単に変更できます。

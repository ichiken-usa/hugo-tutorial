# Hugo チュートリアル: シングルテンプレートの活用方法

Hugoでは、シングルテンプレートを使用して個別のページをレンダリングできます。このガイドでは、シングルテンプレートの基本から作成・カスタマイズ方法までを解説します。

## シングルテンプレートとは？

シングルテンプレートは、Hugoで個別のページをレンダリングするために使用されるテンプレートです。一方、リストテンプレートはリストページ（例: カテゴリーページ）をレンダリングするために使用されます。

### 主な特徴

- **個別ページ用**: シングルテンプレートは、ブログ記事や固定ページなど、個別のコンテンツを表示するために使用されます。
- **デフォルトの場所**: シングルテンプレートは通常、`layouts/_default/single.html`に配置されています。
- **カスタマイズ可能**: テーマのテンプレートを上書きすることで、独自のデザインを適用できます。

---

## シングルテンプレートの活用方法

### 1. シングルテンプレートの場所

Hugoテーマでは、シングルテンプレートは通常以下の場所にあります。

```plaintext
layouts/_default/single.html
```

このファイルを編集することで、個別ページのデザインを変更できます。

---

### 2. テンプレートの上書き

テーマのテンプレートを上書きするには、プロジェクトの`layouts/_default`フォルダに新しい`single.html`ファイルを作成します。このファイルが優先され、テーマのテンプレートが上書きされます。

---

### 3. Hugo変数の活用

Hugoでは、テンプレート内で以下の変数を使用してコンテンツやメタデータを表示できます。

- **`.content`**: Markdownファイルのコンテンツを出力します。
- **`.title`**: フロントマターで定義されたタイトルを表示します。
- **`.date`**: フロントマターで定義された日付を表示します。

以下は、これらの変数を使用したシンプルなテンプレートの例です。

```html
<article>
  <h1>{{ .Title }}</h1>
  <p>公開日: {{ .Date }}</p>
  <div>{{ .Content }}</div>
</article>
```

---

### 4. フロントマター変数の使用

Markdownファイルのフロントマターで定義された変数（例: `author`や`tags`）は、テンプレート内で簡単にアクセスできます。

```html
<p>著者: {{ .Params.author }}</p>
<p>タグ: {{ range .Params.tags }}<span>{{ . }}</span>{{ end }}</p>
```

---

## 重要なポイント

- **シングルテンプレートの役割**: 個別のページをレンダリングするために使用されます。
- **テンプレートの上書き**: プロジェクト内で独自のテンプレートを作成することで、テーマをカスタマイズ可能。
- **Hugo変数の活用**: `.content`や`.title`などの変数を使用して、Markdownファイルのデータをテンプレートに表示できます。

# Hugo インストール手順（Windows向け）

HugoをWindowsにインストールするのはとても簡単です！このガイドでは、Hugoのダウンロードから環境変数の設定まで、初心者でも迷わず進められる手順を詳しく解説します。

---

## このガイドで学べること

- WindowsにHugoをインストールする方法
- Hugo用のフォルダ構成の作成
- GitHubからHugoの実行ファイルをダウンロードする手順
- Hugoファイルの解凍と配置
- コマンドラインからHugoを実行する方法
- PATH環境変数を設定して、どこからでもHugoを使えるようにする方法

---

## 手順

### 1. フォルダを準備する

まず、Cドライブに「Hugo」というフォルダを作成し、その中に「bin」というフォルダを作りましょう。この「bin」フォルダにHugoの実行ファイルを保存します。

### 2. Hugoをダウンロードする

次に、[HugoのGitHubリリースページ](https://github.com/gohugoio/hugo/releases)にアクセスして、自分のWindows OS（32ビットまたは64ビット）に適したバージョンをダウンロードします。

### 3. ファイルを解凍して配置する

ダウンロードしたZIPファイルを解凍し、中にあるHugoの実行ファイルを「bin」フォルダに移動します。必要に応じて、ファイル名を「hugo」に変更しておくと便利です。

### 4. コマンドラインでHugoを実行する

コマンドプロンプトを開き、「bin」フォルダに移動して以下のコマンドを実行します。

```bash
hugo version
```

これでHugoのバージョン情報が表示されれば、インストールは成功です！

### 5. PATH環境変数を設定する

Hugoをどのディレクトリからでも実行できるようにするために、PATH環境変数を設定します。

1. **「システム環境変数の編集」**を開きます（Windowsの検索バーで「環境変数」と入力すると見つかります）。
2. 「システム環境変数」の「Path」を選択して編集をクリックします。
3. 「新規」をクリックして、「C:\Hugo\bin」を追加します。
4. 変更を保存してウィンドウを閉じます。

### 6. 設定を確認する

コマンドプロンプトを再起動し、以下のコマンドを実行して設定が正しく反映されているか確認します。

```bash
hugo version
```

どのディレクトリからでもHugoのバージョン情報が表示されれば、設定完了です！

---

## 重要なポイント

- **フォルダ構成**: Cドライブに「Hugo」フォルダを作成し、その中に「bin」フォルダを配置。
- **環境変数の設定**: PATH変数に「C:\Hugo\bin」を追加することで、どこからでもHugoを実行可能に。
- **確認方法**: `hugo version`コマンドでインストールと設定を確認。

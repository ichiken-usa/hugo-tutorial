# Hugo インストール手順（Windows向け）

## カバーされたトピック

- Windows への Hugo のインストール
- Hugo インストール用フォルダの作成
- GitHub から Hugo 実行ファイルをダウンロード
- Hugo ファイルを正しいディレクトリに解凍・配置
- コマンドラインから Hugo を実行
- Windows の PATH 環境変数を変更して Hugo をグローバルにアクセス可能にする方法

## 重要なポイントや説明

- C ドライブに「Hugo」フォルダを作成し、その中に「bin」フォルダを作成して Hugo ファイルを保存。
- 自分の Windows OS（32ビットまたは64ビット）に適した Hugo バージョンを GitHub のリリースページからダウンロード。
- ダウンロードした ZIP ファイルを「bin」フォルダに解凍。
- 必要に応じて Hugo 実行ファイルの名前を「hugo」に変更。
- 初期状態では「bin」フォルダ内でのみ Hugo コマンドが実行可能。
- Hugo コマンドをどのディレクトリからでも実行できるようにするには、「bin」フォルダのパスを Windows の PATH 環境変数に追加。
- Windows 10 の「システム環境変数の編集」パネルを使用して PATH 変数を編集する手順。
- PATH 変数の更新を確認するには、PATH 変数をエコー表示し、「bin」フォルダ外で `hugo version` コマンドを実行。

## 重要な定義・概念

- **PATH 変数**: 実行可能ファイルの場所を格納するシステム環境変数で、任意のディレクトリからコマンドを実行可能にする。

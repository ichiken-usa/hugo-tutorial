## テンプレートとは？

テンプレートは、Hugoで一貫性のあるHTML構造を作成するためのHTMLスケルトンです。これにより、複数のページで共通のデザインを維持しながら、ページごとに異なるコンテンツを表示できます。

### 主な特徴

- **一貫性のある構造**: テンプレートを使用することで、すべてのページで共通のデザインを適用できます。
- **リストページとシングルページ**: リストページは複数のコンテンツを一覧表示し、シングルページは個別のコンテンツを表示します。
- **柔軟なカスタマイズ**: テンプレートを編集することで、サイト全体のデザインを簡単に変更可能です。

---

## テンプレートの活用方法

### 1. テンプレートの構造と場所

Hugoテーマでは、テンプレートは通常以下の場所に保存されています。

```plaintext
layouts/_default/
```

- **`list.html`**: リストページ（例: ホームページやカテゴリーページ）用のテンプレート。
- **`single.html`**: シングルページ（例: ブログ記事や固定ページ）用のテンプレート。

---

### 2. テンプレートの基本構造

テンプレートは、HTML構造の中にHugo変数を埋め込むことで、動的なコンテンツを表示します。以下は`list.html`の基本例です。

```html
<!DOCTYPE html>
<html>
<head>
  <title>{{ .Site.Title }}</title>
</head>
<body>
  <h1>{{ .Title }}</h1>
  <ul>
    {{ range .Pages }}
      <li><a href="{{ .URL }}">{{ .Title }}</a></li>
    {{ end }}
  </ul>
</body>
</html>
```

---

### 3. テンプレートのカスタマイズ

テンプレートをカスタマイズするには、プロジェクトの`layouts/_default`フォルダにあるテンプレートファイルを編集します。たとえば、`list.html`を編集すると、すべてのリストページに変更が反映されます。

---

### 4. Hugo変数の活用

Hugoでは、以下の変数を使用してテンプレート内でコンテンツやメタデータを表示できます。

- **`.Content`**: Markdownファイルのコンテンツを出力します。
- **`.Title`**: フロントマターで定義されたタイトルを表示します。
- **`.URL`**: ページのURLを取得します。

---

### 5. パーシャルの活用（簡単な紹介）

パーシャルは、テンプレート内で再利用可能なセクションを作成するための仕組みです。たとえば、ヘッダーやフッターをパーシャルとして定義し、複数のテンプレートで共有できます。

```html
{{ partial "header.html" . }}
```

## 重要なポイント

- **テンプレートの役割**: 一貫性のあるHTML構造を提供し、複数のページで共通のデザインを適用します。
- **リストページとシングルページ**: リストページは複数のコンテンツを一覧表示し、シングルページは個別のコンテンツを表示します。
- **テンプレートのカスタマイズ**: テンプレートを編集することで、サイト全体のデザインを簡単に変更可能です。
- **Hugo変数の活用**: `.Content`や`.Title`などの変数を使用して、Markdownファイルのデータをテンプレートに表示できます。

Hugoのテンプレートを活用することで、サイト全体のデザインを効率的に管理できます。テンプレートをカスタマイズすることで、サイトのデザインや構造を柔軟に変更可能です。次のステップでは、条件付きロジックやパーシャルを使用した高度なテンプレート作成方法を学びましょう！

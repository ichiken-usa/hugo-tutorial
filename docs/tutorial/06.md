# Hugo のコンテンツ管理とカスタムリストページの作成

Hugoでは、コンテンツを効率的に整理し、カスタムリストページを作成することで、サイトの構造を柔軟にカスタマイズできます。このガイドでは、コンテンツ管理の基本からリストページのカスタマイズ方法までを解説します。

---

## このガイドで学べること

- Hugoにおけるコンテンツの整理方法
- 新しいHugoコンテンツファイルの作成
- コンテンツファイルをディレクトリに整理する方法
- Hugoの異なるコンテンツタイプ（シングルページとリストページ）
- 下書きコンテンツを含めたHugoサーバーの実行
- ルートレベルディレクトリの自動リストページ作成
- ネストされたディレクトリ用の`_index.md`を使用したカスタムリストページの作成
- 自動生成されたリストページをカスタムコンテンツで上書きする方法

---

## 手順とポイント

### 1. コンテンツファイルの作成と整理

- Hugoのコンテンツファイルは`content`フォルダに保存されます。
- 新しいコンテンツを作成するには、以下のコマンドを使用します。

```bash
hugo new [パス/ファイル名.md]
```

- このコマンドを実行すると、Hugoが自動的にフロントマター（タイトル、日付、下書きステータス）を追加します。

### 2. コンテンツタイプの理解

Hugoでは、以下の2種類のコンテンツが区別されます。

- **シングルページ**: 実際のコンテンツを表示するページ（例: ブログ記事）。
- **リストページ**: 他のページやコンテンツを一覧表示するページ（例: カテゴリーページ）。

### 3. 下書きコンテンツのプレビュー

- 下書きファイルはデフォルトではレンダリングされませんが、以下のコマンドを使用すると下書きも含めてプレビューできます。

```bash
hugo server -D
```

### 4. URL構造とリストページ

- Hugoでは、コンテンツファイルのディレクトリ構造がURLに反映されます。
- `content`フォルダのルートにあるディレクトリには、自動的にリストページが作成されます。
- ネストされたディレクトリには自動的にリストページが作成されないため、手動で`_index.md`ファイルを作成する必要があります。

### 5. カスタムリストページの作成

- 自動生成されたリストページをカスタマイズするには、`_index.md`ファイルを使用します。
- `_index.md`ファイルにカスタムコンテンツを追加することで、リストページを上書きできます。

---

## 重要なポイント

- **フロントマター**: コンテンツファイルの先頭にあるメタデータ（例: タイトル、日付、下書きステータス）。
- **シングルページコンテンツ**: Markdownファイルから実際の情報を表示するコンテンツページ。
- **リストページコンテンツ**: 他のページやコンテンツを一覧表示するディレクトリのようなページ。
- **下書きフラグ**: フロントマター内の設定で、ページを下書きとしてマークし、指定がない限りレンダリングを防ぎます。
- **_index.md**: Hugoでリストページを作成または上書きするために使用される特別なMarkdownファイル。

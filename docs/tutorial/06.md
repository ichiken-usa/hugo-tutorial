## 重要なポイントや説明

- Hugo のコンテンツファイルは `content` フォルダに保存され、各ページは Markdown ファイルとして管理。
- 新しいコンテンツファイルを作成すると、Hugo は自動的にフロントマター（タイトル、日付、下書きステータス）を追加。
- Hugo は以下の2種類のコンテンツを区別:
  - **シングルページ**: 実際のコンテンツを表示するページ。
  - **リストページ**: 他のページやコンテンツを一覧表示するページ。
- 下書きファイルはデフォルトではレンダリングされないが、`hugo server -D` を使用すると下書きも含めてプレビュー可能。
- URL はコンテンツファイルのディレクトリ構造を反映。
- `content` フォルダのルートにあるディレクトリには、自動的にリストページが作成される。
- ネストされたディレクトリには自動的にリストページが作成されないため、手動で `_index.md` ファイルを作成する必要がある。
- 自動生成されたリストページは、カスタムコンテンツを追加することで `_index.md` ファイルを使用して上書き可能。
- 使用するテーマによって、コンテンツの表示方法や整理方法が異なる。

## 重要な定義・概念

- **フロントマター**: コンテンツファイルの先頭にあるメタデータ（例: タイトル、日付、下書きステータス）。
- **シングルページコンテンツ**: Markdown ファイルから実際の情報を表示するコンテンツページ。
- **リストページコンテンツ**: 他のページやコンテンツを一覧表示するディレクトリのようなページ。
- **下書きフラグ**: フロントマター内の設定で、ページを下書きとしてマークし、指定がない限りレンダリングを防ぐ。
- **_index.md**: Hugo でリストページを作成または上書きするために使用される特別な Markdown ファイル。

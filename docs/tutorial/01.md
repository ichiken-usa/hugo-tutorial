## 重要なポイントや説明

- 静的サイトジェネレーターは、静的 HTML ページと重い CMS プラットフォームの中間的な選択肢を提供。
- Hugo は Go 言語で書かれており、マルチスレッドをサポートしているため非常に高速。
- 動的ウェブサイトは、ユーザーごとにパーソナライズされたコンテンツを動的に生成（例: Facebook）。
- 静的ウェブサイトは、すべてのユーザーに同じハードコーディングされたコンテンツを提供するため、高速でホスティングが簡単。
- 動的ウェブサイトは柔軟でスケーラブルだが、サーバーリソースとメンテナンスが必要。
- 静的ウェブサイトは柔軟性に欠けるが、非常に高速で提供が簡単。
- Hugo は Markdown でコンテンツを記述でき、HTML やデータベース管理が不要。
- Hugo は無料でオープンソース、強力なコミュニティに支えられている。
- コースでは基本から始め、テンプレート、レイアウト、条件ロジックなどの高度なトピックに進む。

## 重要な定義・概念

- **静的ウェブサイト**: 固定されたコンテンツをすべてのユーザーに同じように提供するウェブサイト。
- **動的ウェブサイト**: ユーザーに応じて動的にパーソナライズされたコンテンツを生成するウェブサイト。
- **静的サイトジェネレーター**: コンテンツとテンプレートから静的なウェブページを生成するツール。
- **Hugo**: Go 言語で書かれた高速な静的サイトジェネレーター。

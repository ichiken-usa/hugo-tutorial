# Hugo チュートリアル: Baseテンプレートとブロックの活用方法

Hugoでは、Baseテンプレートとブロックを使用することで、モジュール化された柔軟なレイアウトを作成できます。このガイドでは、Baseテンプレートの基本からブロックの定義と活用方法までを解説します。

---

## このガイドで学べること

- HugoにおけるBaseテンプレートとブロックの基本
- `baseof.html`を使用したレイアウトの整理方法
- Hugoテンプレートでのブロックの定義と使用方法
- シングルテンプレートやリストテンプレートでのブロックの作成と上書き
- モジュール化されたレイアウトの利点とブロックの活用による効率化

---

## Baseテンプレートとブロックとは？

Baseテンプレート（`baseof.html`）は、Hugoサイト全体のベースとなるテンプレートです。ブロックを使用することで、他のテンプレート（例: `single.html`や`list.html`）からBaseテンプレートにコンテンツを挿入できます。

### 主な特徴

- **Baseテンプレート**: サイト全体の共通レイアウトを定義するテンプレート。
- **ブロック**: Baseテンプレート内で定義され、他のテンプレートから内容を上書きできるセクション。
- **柔軟性**: ブロックを使用することで、特定のテンプレートだけをカスタマイズしながら、共通部分を再利用可能。

---

## Baseテンプレートとブロックの活用方法

### 1. Baseテンプレートの作成

Baseテンプレートは、`layouts/_default/baseof.html`に作成します。以下は基本的な構造の例です。

```html
<!DOCTYPE html>
<html>
<head>
  <title>{{ .Site.Title }}</title>
</head>
<body>
  <header>
    <h1>{{ .Site.Title }}</h1>
  </header>
  <main>
    {{ block "main" . }}{{ end }}
  </main>
  <footer>
    <p>© {{ now.Year }}</p>
  </footer>
</body>
</html>
```

- **`block "main"`**: 他のテンプレートで上書き可能なメインコンテンツエリアを定義。

---

### 2. ブロックの定義と上書き

他のテンプレート（例: `single.html`や`list.html`）で、Baseテンプレートのブロックを上書きしてカスタマイズします。

#### `single.html`の例

```html
{{ define "main" }}
<article>
  <h1>{{ .Title }}</h1>
  <p>公開日: {{ .Date }}</p>
  <div>{{ .Content }}</div>
</article>
{{ end }}
```

#### `list.html`の例

```html
{{ define "main" }}
<ul>
  {{ range .Pages }}
    <li><a href="{{ .URL }}">{{ .Title }}</a></li>
  {{ end }}
</ul>
{{ end }}
```

---

### 3. ブロックの利点

- **コードの重複を削減**: 共通部分（例: ヘッダーやフッター）をBaseテンプレートにまとめることで、コードの重複を防ぎます。
- **柔軟なカスタマイズ**: 特定のテンプレートだけをカスタマイズし、他のテンプレートには影響を与えません。
- **保守性の向上**: レイアウトの変更が必要な場合、Baseテンプレートを編集するだけでサイト全体に反映されます。

---

## 重要なポイント

- **Baseテンプレートの役割**: サイト全体の共通レイアウトを定義し、他のテンプレートで再利用可能。
- **ブロックの活用**: Baseテンプレート内で定義されたブロックを上書きすることで、特定のテンプレートをカスタマイズ可能。
- **効率的なレイアウト管理**: ブロックを使用することで、モジュール化された柔軟なレイアウトを実現。

---

## 重要な定義・概念

- **Baseテンプレート**: サイト全体のベースとなるテンプレート（`baseof.html`）。
- **ブロック**: Baseテンプレート内で定義され、他のテンプレートから内容を挿入または上書きできるセクション。
- **Define**: Hugoテンプレートでブロックの内容を指定するコマンド。
- **Override（上書き）**: 子テンプレートでBaseテンプレートのブロック内容を置き換えること。

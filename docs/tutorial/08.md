## 重要なポイントや説明

- Hugo のコンテンツファイルに含まれるデフォルトのフロントマターは、アーキタイプから生成される。
- `archetypes` フォルダ内の `default.md` ファイルが、新しいコンテンツファイル作成時のフロントマターのテンプレートとして機能。
- `default.md` を編集することで、すべての新しいコンテンツファイルのデフォルトフロントマターを変更可能。
- 特定のディレクトリ専用のアーキタイプ（例: `dir1.md`）を作成することで、特定のディレクトリ内で作成されるコンテンツファイルのフロントマターをカスタマイズ可能。
- Hugo は新しいコンテンツファイルを作成する際、ディレクトリ固有のアーキタイプを優先して使用し、それがない場合に `default.md` を使用する。

## 重要な定義・概念

- **アーキタイプ (Archetype)**: Hugo が新しいコンテンツファイルを作成する際に使用するデフォルトのフロントマターテンプレート。
- **フロントマター (Front Matter)**: コンテンツファイルの先頭にあるメタデータで、タイトル、日付、下書きステータス、著者などの情報を含む。

## アーキタイプの活用例

### デフォルトのアーキタイプの編集

1. `archetypes/default.md` を開き、以下のように編集:

   ```markdown
   ---
   title: "{{ replace .Name "-" " " | title }}"
   date: {{ .Date }}
   draft: true
   author: "デフォルトの著者名"
   tags: []
   ---
   ```

2. この設定により、新しいコンテンツファイル作成時に自動的に上記のフロントマターが挿入される。

### ディレクトリ固有のアーキタイプの作成

1. `archetypes/dir1.md` を作成し、以下を記述:

   ```markdown
   ---
   title: "{{ replace .Name "-" " " | title }}"
   date: {{ .Date }}
   draft: false
   category: "特定のカテゴリ"
   ---
   ```

2. `content/dir1` ディレクトリ内で新しいコンテンツを作成すると、このアーキタイプが適用される。

### 新しいコンテンツファイルの作成

以下のコマンドを使用して、新しいコンテンツファイルを作成:

```bash
hugo new dir1/example.md
```

- この場合、`archetypes/dir1.md` が適用される。

## アーキタイプの利点

- フロントマターの一貫性を保つ。
- ディレクトリごとに異なるテンプレートを適用可能。
- コンテンツ作成の効率化とエラー削減に寄与。

アーキタイプを活用することで、Hugo サイトのコンテンツ管理がより柔軟で効率的になります。

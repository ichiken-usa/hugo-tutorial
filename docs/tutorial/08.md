# Hugo のアーキタイプの概要と活用方法

Hugoでは、アーキタイプを使うことで、新しいコンテンツファイル作成時のフロントマターを効率的に管理できます。このガイドでは、アーキタイプの基本から活用方法までを解説します。

---

## このガイドで学べること

- Hugoにおけるアーキタイプの基本
- デフォルトのフロントマターのカスタマイズ方法
- ディレクトリ固有のアーキタイプの作成方法
- アーキタイプを活用した効率的なコンテンツ管理

---

## アーキタイプとは？

アーキタイプは、Hugoが新しいコンテンツファイルを作成する際に使用するフロントマターテンプレートです。これにより、フロントマターの一貫性を保ちながら、効率的にコンテンツを作成できます。

### 主な特徴

- **デフォルトテンプレート**: `archetypes/default.md`がすべての新しいコンテンツファイルのフロントマターを定義。
- **カスタマイズ可能**: ディレクトリ固有のアーキタイプを作成して、特定のコンテンツに適したフロントマターを設定可能。
- **優先順位**: Hugoはディレクトリ固有のアーキタイプを優先し、それがない場合に`default.md`を使用。

---

## アーキタイプの活用例

### 1. デフォルトのアーキタイプの編集

`archetypes/default.md`を編集することで、すべての新しいコンテンツファイルに適用されるフロントマターを変更できます。

```markdown
---
title: "{{ replace .Name "-" " " | title }}"
date: {{ .Date }}
draft: true
author: "デフォルトの著者名"
tags: []
---
```

この設定により、新しいコンテンツファイル作成時に自動的に上記のフロントマターが挿入されます。

---

### 2. ディレクトリ固有のアーキタイプの作成

特定のディレクトリ専用のアーキタイプを作成することで、ディレクトリごとに異なるフロントマターを設定できます。

1. `archetypes/dir1.md`を作成し、以下を記述します。

```markdown
---
title: "{{ replace .Name "-" " " | title }}"
date: {{ .Date }}
draft: false
category: "特定のカテゴリ"
---
```

2. `content/dir1`ディレクトリ内で新しいコンテンツを作成すると、このアーキタイプが適用されます。

---

### 3. 新しいコンテンツファイルの作成

以下のコマンドを使用して、新しいコンテンツファイルを作成します。

```bash
hugo new dir1/example.md
```

この場合、`archetypes/dir1.md`が適用され、指定されたフロントマターが自動的に挿入されます。

---

## アーキタイプの利点

- **フロントマターの一貫性**: すべてのコンテンツファイルで統一されたメタデータを使用可能。
- **柔軟なカスタマイズ**: ディレクトリごとに異なるテンプレートを適用できる。
- **効率的なコンテンツ作成**: 手動でフロントマターを記述する手間を削減し、エラーを防止。

## 重要なポイントや説明

- **ショートコード** は、Markdown ファイルに複雑な HTML 要素を簡単に埋め込むための事前定義された HTML チャンク。
- Hugo には、YouTube 動画埋め込み用のショートコードを含む、いくつかの事前定義されたショートコードが用意されている。
- **YouTube ショートコード** は、YouTube 動画 ID をパラメータとして受け取る。
  - 例: `https://www.youtube.com/watch?v=2xkNJL4gJ9E` の場合、`2xkNJL4gJ9E` が動画 ID。
- ショートコードを使用することで、Markdown ファイルをクリーンに保ち、iframe のような複雑な HTML を手動で記述する必要がなくなる。
- Hugo サイトがレンダリングされると、ショートコードは対応する HTML に置き換えられ、埋め込みコンテンツが表示される。
- Markdown ファイルからショートコードを削除すると、埋め込みコンテンツもサイトから削除される。
- Hugo の公式ドキュメントには、利用可能なショートコードのリストが記載されているため、参照を推奨。
- カスタムショートコードはショートコードテンプレートを使用して作成可能で、これについては今後のレッスンで解説予定。

## 重要な定義・概念

- **ショートコード**: Markdown ファイルに簡単にコンテンツを埋め込むための事前定義された HTML チャンク。
- **YouTube ショートコード**: YouTube 動画を埋め込むための Hugo の事前定義ショートコードで、動画 ID をパラメータとして使用。
- **ショートコードテンプレート**: カスタムショートコードを定義するための方法（後のレッスンで解説予定）。

## YouTube ショートコードの使用例

以下の URL の動画を埋め込む場合を例に説明します:
`https://www.youtube.com/watch?v=2xkNJL4gJ9E&list=PLLAZ4kZ9dFpOnyRlyS-liKL5ReHDcj4G3&index=9`

1. 動画 ID を取得:
   - URL の `v=` の後に続く部分が動画 ID（この例では `2xkNJL4gJ9E`）。
2. Markdown ファイルに以下のように記述:

   ```markdown
      {{< youtube 2xkNJL4gJ9E >}}
   ```

3. Hugo サーバーを起動してプレビュー:

   ```bash
   hugo server
   ```

ブラウザで [http://localhost:1313](http://localhost:1313) を開き、埋め込まれた動画を確認。

## ショートコードの利点

- Markdown ファイルをシンプルに保つ。
- 再利用可能なコードで効率的に埋め込みを実現。
- 動的に HTML を生成するため、メンテナンスが容易。

Hugoでは、ショートコードを使うことで、Markdownファイルに複雑なHTML要素を簡単に埋め込むことができます。このガイドでは、ショートコードの基本から活用方法までを解説します。

## ショートコードとは？

ショートコードは、Markdownファイルに複雑なHTML要素を簡単に埋め込むための事前定義されたHTMLチャンクです。これにより、Markdownファイルをクリーンに保ちながら、動的なコンテンツを簡単に追加できます。

### 主な特徴

- **簡単な埋め込み**: iframeなどの複雑なHTMLを手動で記述する必要がなくなります。
- **再利用可能**: 同じショートコードを複数の場所で使用可能。
- **動的なレンダリング**: Hugoがサイトをレンダリングする際に、ショートコードが対応するHTMLに置き換えられます。

---

## YouTubeショートコードの使用例

Hugoには、YouTube動画を埋め込むための事前定義ショートコードが用意されています。以下はその使用例です。

### 1. 動画IDを取得

YouTube動画のURLから動画IDを取得します。  
例: `https://www.youtube.com/watch?v=2xkNJL4gJ9E`  
この場合、`2xkNJL4gJ9E`が動画IDです。

### 2. Markdownファイルに記述

以下のようにショートコードを記述します。

```markdown
{{< youtube 2xkNJL4gJ9E >}}
```

### 3. プレビュー

Hugoサーバーを起動して、埋め込まれた動画をプレビューします。

```bash
hugo server
```

ブラウザで[http://localhost:1313](http://localhost:1313)にアクセスすると、動画が正しく埋め込まれていることを確認できます。

## ショートコードの利点

- **Markdownファイルをシンプルに保つ**: 複雑なHTMLを直接記述する必要がありません。
- **効率的な埋め込み**: 再利用可能なコードで効率的にコンテンツを追加可能。
- **メンテナンスが容易**: ショートコードを変更するだけで、すべての関連コンテンツが更新されます。

---

## 重要なポイント

- **事前定義ショートコード**: HugoにはYouTube埋め込みなどの便利なショートコードが用意されています。
- **カスタムショートコード**: 独自のショートコードを作成することで、さらに柔軟なコンテンツ管理が可能です（詳細は今後のレッスンで解説します）。
- **公式ドキュメントの活用**: Hugoの公式ドキュメントには、利用可能なショートコードのリストが記載されています。

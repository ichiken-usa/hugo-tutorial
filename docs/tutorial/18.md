## Hugoの関数とは？

Hugoの関数は、特定のタスクを実行するために事前に用意されたコードの一部です。これにより、テンプレート内での操作が簡単になります。

### 主な特徴

- **テンプレート専用**: 関数は`layouts`フォルダ内のテンプレートでのみ使用可能です。
- **簡単な呼び出し**: 関数はダブル中括弧（`{{ }}`）内で関数名とパラメータを指定して呼び出します。
- **多様な用途**: 文字列操作、算術演算、ループ処理など、さまざまなタスクに使用可能です。

---

## Hugo関数の活用方法

### 1. 一般的な関数の使用例

#### `truncate`関数

文字列を指定した長さに短縮します。

```html
<p>{{ truncate 20 "これは非常に長い文字列です。" }}</p>
```

出力: `これは非常に長い...`

#### 算術関数

基本的な算術演算を実行します。

```html
<p>{{ add 5 3 }}</p> <!-- 出力: 8 -->
<p>{{ sub 10 4 }}</p> <!-- 出力: 6 -->
```

#### `singularize`関数

複数形の単語を単数形に変換します。

```html
<p>{{ singularize "categories" }}</p> <!-- 出力: category -->
```

---

### 2. `range`関数を使用したループ処理

`range`関数を使用すると、セクション内のすべてのページをループ処理できます。

```html
<ul>
  {{ range .Pages }}
    <li><a href="{{ .URL }}">{{ .Title }}</a></li>
  {{ end }}
</ul>
```

- **`.Pages`**: 現在のセクション内のすべてのページを表します。
- **ループ内での変数アクセス**: 各ページのタイトルやURLなどの変数にアクセス可能。

---

### 3. 関数と変数の組み合わせ

関数を変数と組み合わせて動的なコンテンツを生成できます。

```html
{{ $shortTitle := truncate 10 .Title }}
<p>{{ $shortTitle }}</p>
```

---

### 4. HTMLとCSSでの関数の活用

関数をHTMLやCSSと組み合わせて、動的なスタイリングを実現できます。

```html
<div style="width: {{ add 50 20 }}px;">
  動的な幅のボックス
</div>
```

## 重要な定義・概念

- **関数**: Hugoで特定のタスクを実行するための事前定義されたコード。
- **`truncate`**: 文字列を指定した長さに短縮する関数。
- **`range`**: コレクション（例: セクション内のページ）をループ処理するための関数。
- **`.Pages`**: 現在のセクション内のすべてのページを表す変数。

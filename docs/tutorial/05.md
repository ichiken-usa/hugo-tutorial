# Hugo テーマの導入と設定方法

Hugoでは、テーマを使うことで簡単にウェブサイトのデザインを変更できます。このガイドでは、テーマの選択からインストール、設定、プレビューまでの手順をわかりやすく解説します。

---

## このガイドで学べること

- Hugoテーマの概要
- 公式Hugoテーマサイトでのテーマの検索と選択方法
- GitHubからHugoテーマをダウンロードする方法
- Hugoプロジェクトにテーマをインストールする方法
- `config.toml`ファイルでテーマを設定する方法
- Hugoサーバーを実行してテーマをプレビューする方法

---

## 手順

### 1. テーマを選ぶ

Hugoの公式テーマサイト（[Hugo Themes](https://themes.gohugo.io/)）で、好みのテーマを探しましょう。テーマのプレビューや説明を確認して、自分のプロジェクトに合ったものを選びます。

おすすめのテーマ例:  
- [hugo-PaperMod](https://github.com/adityatelange/hugo-PaperMod)（シンプルで更新頻度が高い）

---

### 2. テーマをインストールする

選んだテーマをインストールするには、以下の手順を実行します。

#### GitHubリポジトリをクローンする場合

ターミナルで以下のコマンドを実行して、テーマをプロジェクトの`themes`フォルダにクローンします。

```bash
git clone https://github.com/adityatelange/hugo-PaperMod themes/hugo-PaperMod
```

#### ZIPファイルをダウンロードする場合

1. テーマのGitHubページからZIPファイルをダウンロードします。
2. ダウンロードしたZIPファイルを解凍し、解凍したフォルダを`themes`フォルダに移動します。

---

### 3. テーマを設定する

テーマを有効化するには、プロジェクトの`config.toml`ファイルを編集し、以下のようにテーマ名を指定します。

```toml
theme = "hugo-PaperMod"
```

---

### 4. テーマをプレビューする

Hugoサーバーを起動して、テーマが正しく適用されているか確認します。

```bash
hugo server
```

ブラウザで[http://localhost:1313](http://localhost:1313)にアクセスすると、選択したテーマでサイトが表示されます。

---

## 重要なポイント

- **Hugoテーマとは？**  
  テンプレートやレイアウトのコレクションで、ウェブサイトのデザインを簡単に変更できます。

- **テーマのインストール方法**  
  GitHubリポジトリをクローンするか、ZIPファイルをダウンロードして`themes`フォルダに配置します。

- **`config.toml`ファイルの設定**  
  テーマ名を指定することで、Hugoがそのテーマを使用します。

- **プレビューの確認**  
  `hugo server`コマンドでローカルサーバーを起動し、ブラウザで確認できます。

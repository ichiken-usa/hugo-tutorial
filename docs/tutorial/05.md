## 重要なポイントや説明

- **Hugo テーマ** は、テンプレートやレイアウトのコレクションで、ウェブサイトを自動的に構築するためのもの。
- HTML、CSS、JavaScript を手動で記述したくない人にとって便利。
- 公式 Hugo テーマサイトでは、プレビューや説明付きの事前構築されたテーマのギャラリーを提供。[チュートリアルで使用するテーマ](https://github.com/giraffeacademy/ga-hugo-theme)
  - このテーマだと古くて修正なしではビルドできない。
  - 更新の新しい別のシンプルなテーマでテストした方が良い。人気のHugoBlox系はややこしくてチュートリアルには不向き。一旦スターも多く更新も新しい[hugo-PaperMod](https://github.com/adityatelange/hugo-PaperMod)でテスト
- テーマは GitHub リポジトリにホストされており、README ファイルにドキュメントが含まれている。
- テーマは、GitHub リポジトリをクローンするか、ZIP ファイルをダウンロードして解凍し、Hugo の `themes` フォルダに配置することでインストール可能。
- テーマフォルダの構造は、アーキタイプ、レイアウト、`theme.toml` 設定ファイルを含む小さな Hugo プロジェクトのようなもの。
- テーマを有効化するには、`config.toml` ファイルにテーマ名を指定する行を追加する必要がある:

  ```toml
  theme = 'テーマ名'
  ```

- Hugo サーバーをローカルで実行して、選択したテーマでウェブサイトをプレビュー可能。
  
  ```bash
  hugo servers
  ```

- [http://localhost:1313](http://localhost:1313)

## 重要な定義・概念

- Hugo テーマ: Hugo ウェブサイトをスタイル設定し、構成するテンプレートとレイアウトのパッケージ。
- GitHub リポジトリ: Hugo テーマが保存・管理されている場所。
- config.toml: Hugo プロジェクトのメイン設定ファイルで、テーマを指定する。
- hugo server: Hugo ウェブサイトをプレビューするためのローカルサーバーを実行するコマンド。

# Hugo チュートリアル: パーシャルテンプレートの活用方法

Hugoでは、パーシャルテンプレートを使用して、ヘッダーやフッター、ナビゲーションなどのウェブサイト要素をモジュール化できます。このガイドでは、パーシャルテンプレートの基本から作成方法、変数のスコープやカスタムデータの渡し方までを解説します。

---

## このガイドで学べること

- Hugoにおけるパーシャルテンプレートの基本
- パーシャルテンプレートの作成と使用方法（ヘッダーの例）
- パーシャルに変数やスコープを渡す方法
- 辞書を使用してカスタムデータをパーシャルに渡す方法

---

## パーシャルテンプレートとは？

パーシャルテンプレートは、ウェブサイトのヘッダーやフッター、ナビゲーションなどの再利用可能なHTMLテンプレートフラグメントです。これにより、コードの重複を減らし、メンテナンス性を向上させることができます。

### 主な特徴

- **モジュール化**: ヘッダーやフッターなどの共通要素を分離して管理可能。
- **`partials`フォルダ**: パーシャルテンプレートは`layouts/partials`フォルダ内に保存されます。
- **簡単な挿入**: `{{ partial "partialname" . }}`を使用してテンプレートに挿入可能。

---

## パーシャルテンプレートの活用方法

### 1. パーシャルテンプレートの作成

以下は、`layouts/partials/header.html`に保存するヘッダーの例です。

```html
<header>
  <h1>{{ .Site.Title }}</h1>
  <nav>
    <ul>
      <li><a href="/">ホーム</a></li>
      <li><a href="/about/">概要</a></li>
    </ul>
  </nav>
</header>
```

---

### 2. パーシャルテンプレートの使用

パーシャルテンプレートを使用するには、テンプレート内で`partial`関数を呼び出します。

```html
{{ partial "header.html" . }}
```

- **`"header.html"`**: 使用するパーシャルテンプレートの名前。
- **`.`**: 現在のスコープ（すべての変数）をパーシャルに渡します。

---

### 3. 辞書を使用したカスタムデータの渡し方

辞書を使用して、パーシャルテンプレートにカスタムデータを渡すことができます。

#### 辞書を渡す例

```html
{{ partial "header.html" (dict "customTitle" "カスタムタイトル" "customNav" .Site.Menus.main) }}
```

#### パーシャルテンプレート内での使用例

```html
<header>
  <h1>{{ .customTitle }}</h1>
  <nav>
    <ul>
      {{ range .customNav }}
        <li><a href="{{ .URL }}">{{ .Name }}</a></li>
      {{ end }}
    </ul>
  </nav>
</header>
```

- **`dict`**: キーと値のペアを作成するための関数。
- **カスタムデータ**: パーシャル内で`{{ .customTitle }}`や`{{ .customNav }}`としてアクセス可能。

---

## 重要なポイント

- **パーシャルテンプレートの役割**: 再利用可能なHTMLフラグメントを作成し、ウェブサイトの要素をモジュール化します。
- **スコープの活用**: `.`を使用して現在のテンプレートの変数をパーシャルに渡します。
- **辞書の使用**: カスタムデータをパーシャルに渡すことで、柔軟なテンプレート設計が可能になります。

---

## 重要な定義・概念

- **パーシャルテンプレート**: 再利用可能なHTMLテンプレートフラグメント。
- **スコープ（`.`）**: 現在のテンプレートやパーシャルでアクセス可能な変数の集合。
- **辞書（`dict`）**: キーと値のペアを作成し、カスタムデータをパーシャルに渡すためのデータ構造。

---

## まとめ

Hugoのパーシャルテンプレートを活用することで、ウェブサイトの要素をモジュール化し、効率的に管理できます。辞書を使用してカスタムデータを渡すことで、さらに柔軟なテンプレート設計が可能になります。公式ドキュメントを参考にしながら、さまざまなパーシャルテンプレートを試してみましょう！
